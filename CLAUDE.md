# Правила работы в этом репозитории

## Целевые действия — только по команде «Твори»

Любое **целевое действие** выполняется только по отдельной явной команде **«Твори»** от пользователя:
- смержить PR/ветку в `main`
- создать новую ветку
- закоммитить и запушить изменения (в том числе в уже существующую рабочую ветку)
- изменить код (например, `index.html`)

Одно «Твори» разрешает ровно один раунд действий. Оно не накапливается и не переносится на следующую задачу/идею — как только тема меняется или предыдущая задача завершена, для нового целевого действия нужно снова дождаться отдельного «Твори».

## Всё остальное — без ограничений

Обсуждение, объяснение кода, исследование идей, планирование, ответы на вопросы, чтение файлов — это не целевые действия, они не требуют «Твори» и не должны сами по себе приводить к коммиту/пушу/мержу.

Если неясно, считается ли что-то «целевым действием», — переспросить у пользователя, а не действовать по своей инициативе.

## Правки index.html касаются всех, у кого он загружен

У приложения нет бэкенда и аккаунтов — это один HTML-файл, а данные каждого пользователя лежат только в его собственном `localStorage`. Любая правка `index.html` уходит в общий файл и применяется абсолютно ко всем, кто его загрузит, а не только к текущему пользователю.

Если просьба разумна только для одного конкретного человека (например, разовая правка чьих-то личных данных/состояния, а не общей логики) — не зашивать это в общий код. В таком случае: указать на это несоответствие явно и предложить решение, которое не трогает общий код (например, снипет, который сам пользователь один раз выполняет у себя в консоли браузера, патча только свой `localStorage`), вместо правки и коммита в репозиторий.

Это не отдельное исключение из правила выше, а его частный случай: любая фактическая правка `index.html` (в том числе «личная») — по-прежнему целевое действие и требует своего отдельного «Твори», как и любая другая правка кода. А вот сам снипет для консоли пользователя правкой репозитория не является, поэтому «Твори» для него не нужен.
